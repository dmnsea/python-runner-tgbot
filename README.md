# python-runner-tgbot
Учебный проект

## Правила репозитория
- **В коде не должно быть токена бота**
- Ветка `main` = прод
- Вся разработка в отдельных ветках
- Веткам дается осмысленное название

## Развертывание и запуск

### Из исходного кода:

Реквизиты:
- [Poetry](https://python-poetry.org/docs/#installation)
- [Docker](https://docs.docker.com/get-docker/)

Склонируйте репозиторий:
```bash
git clone git@github.com:NEK-RA/python-runner-tgbot.git
```

Перейдите в папку проекта и установите зависимости с помощью Poetry:
```bash
poetry install
```

После установки зависимостей, задайте все переменные в `.env` файл - в репозитории доступен `example.env` файл, в котором необходимо указать токен бота, после чего его можно использовать, предварительно переименовав:
```bash
mv example.env .env
```

Теперь вы можете запустить бота следующим образом:
```bash
poetry run bot
```
